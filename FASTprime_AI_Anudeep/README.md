# FASTprime – AI Generated Implementation

## Description

This folder contains the AI-generated solution for the FASTprime project.

The code was generated using an AI tool based on the given problem statement. The aim of this implementation is to compare AI-generated logic with the manually written (man-made) solution.

The program computes prime numbers in a given range using multiple child processes and measures execution time.

---

## Prompt Used

The following prompt was given to generate the code:

"Write a C program to compute prime numbers in a given range using multiple child processes. Use fork(), signal(), kill(), file handling (open, write, close), system calls and measure execution time. Store primes in a file and analyze performance."

---

## Concepts Used in AI Code

- fork() – Process creation  
- signal() – Signal handling  
- kill() – Parent notification  
- open(), write(), close() – File operations  
- gettimeofday() – Execution time measurement  
- system("lscpu") – CPU information  

---

## Difference from Man-made Code

- Includes error handling for system calls.  
- Uses balanced workload division.  
- More structured formatting.  

This implementation helps in understanding how AI approaches the same problem differently.
